# Cinque siti, cinque settori

Cinque siti HTML statici, uno per settore, costruiti con l'AI per dimostrare un punto: con lo strumento giusto e la voglia di usarlo bene, la parte che si vede di un sito la fa chiunque.

| Sito | Settore | Cosa c'è dentro |
|---|---|---|
| [Forgia Training Club](forgia/) | Palestra | stato aperto/chiuso live, palinsesto, calcolatore massimale con bilanciere animato, recensioni automatiche |
| [Trattoria La Grangia](grangia/) | Ristorante | piatto del giorno disegnato e rotante, menu animato con abbinamento vini, prenotazione con orari |
| [Studio Dentistico Morandi](morandi/) | Studio medico | odontogramma cliccabile, slider prima/dopo, prenotazione a step, calcolatore rate |
| [Torrefazione Ottone](ottone/) | E-commerce | ruota degli aromi, quiz "trova il tuo caffè", carrello funzionante |
| [Meridiana Viaggi](meridiana/) | Agenzia viaggi | mappamondo 3D da girare, zoom sul punto cliccato, terminatore giorno/notte reale, Street View |

Tutto in HTML, CSS e JavaScript, un file per sito, niente build. Le attività sono di fantasia.
